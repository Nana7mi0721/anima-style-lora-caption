# 按训练目标的打标细则与 Tagger 标定

> 本文件为 [Anima_style_LoRA_打标指南.md](./Anima_style_LoRA_打标指南.md) §5、§6 的按需展开文档，仅在确定具体 LoRA 目标类型或使用 WD14 类本地 tagger 时读取。

---

## 1. 人物 / 角色 LoRA

1. **角色名 tag 与触发词二选一**：一旦 `@触发词`（或裸词触发词）承担该角色身份，必须删除数据集里的原角色名标签（如 `furina_(genshin_impact)`），否则触发词与角色名争夺同一概念信号。
2. **客串角色不擅自定名**：仅出现 1~3 次的客串角色，**人数照实标（如 `2girls`），身份不写**；若在数据集中反复出现（≥4 次），先由 [build_tag_table.py](../scripts/build_tag_table.py) 生成 `char_freq.csv`，交由用户裁决是否保留。
3. **固有特征的取舍（核心决策）**：
   - **全部写出**：发色、瞳色、标志性发饰在推理时保持可调（换发色/换造型灵活），适合通用场景与新手。
   - **省略不写**：让触发词吸收固有外貌，推理 prompt 更短，但后续几乎无法改发色/瞳色。
   - **进阶混合剪裁**：只剪真正恒定不变的特征，**硬判据为出现比例 ≥0.9**；一次性或偶发状态（如 `wet hair`、`blush`）绝不可剪切。
4. **变化因素必须逐张写出**：姿势、服装、表情、视线（槽位 2）、场景背景、镜头构图必须逐张如实标注，否则会被模型绑定进角色本体。

---

## 2. 画师风格 LoRA

1. **`@` 前缀必用**：Anima 官方模型卡明确指出画师标签不加 `@` 触发效果会非常弱。
2. **绝不描述「风格」本身**：禁止写入 `thick outlines`、`low saturation`、`beautiful eyes`、`painterly` 等风格评价词——风格信号必须完全留给 LoRA 权重吸收。
3. **审美与质量词禁区**：`masterpiece`、`best quality` 等全集恒定质量词与触发词强共现时会产生严重纠缠，一律删除。
4. **内容彻底解耦**：把不同角色外貌、服装、动作、背景、光影、构图全部写清楚，让「画风」成为数据集中唯一未被标签解释掉的残差信号。
5. **常驻高频角色的处理**：画师个人数据集常存在某个看板娘或固定角色高频出现（甚至 90% 以上）。保留该角色 tag 能分流外貌特征，但有与画风强耦合的风险——默认按 ≥4 阈值写入，最终去留交用户裁决（并在 [workflow.md](../assets/workflow.md) Stage 1.5b 确认 `char_roster.json`）。
6. **验收标准**：不在训练集原角色上比「像不像」，而在**陌生跨领域内容（男性、老人、动物、建筑、机械、纯风景）上能否保持画风且不污染内容语义**。

---

## 3. 服装 LoRA

- **四层严格解耦**：Caption 必须清楚分离 **角色外貌 / 目标服装本体 / 姿势动作 / 场景环境** 四层标签。
- 若训练集总是同一角色穿该服装且未写出角色特征，模型会学成「该角色 = 这套衣服」，换人穿即崩坏。
- **数据集构建建议**：覆盖不同体型、发色、人种与多角度穿同一套服装的数据最有价值；穿戴状态（如 `open jacket`、`skirt lift`、`unbuttoned`）须逐张标明。

---

## 4. 物体 / 概念 / 场景 LoRA

- **物体 / 道具**：必须标清**朝向、开合与交互状态**（如 `open` / `closed` / `folded` / `worn` / `holding` / `in use`），这是物体 LoRA 最常见的语义纠缠源。
- **场景 / 环境**：**构图与景别多样性（远景/中景/近景、横构图/竖构图）是第一要求**；每张须写明空间关系、时间（`day`/`night`/`sunset`）与天气/光影，避免触发词绑定单一视角。
- **复杂设计语言**：如特定机甲体系、建筑流派或 UI 风格，按「画师风格 LoRA」路线做内容解耦处理。

## 5. WD14 类 Tagger 参数与标定（若使用本地自动初稿）

当无 booru 权威源、需用本地 WD14 tagger 产出来源 C 初稿时，必须执行以下校准与后处理：

| 项 | 建议与规则 | 说明 |
|---|---|---|
| **通用阈值** | `wd-eva02-large-tagger-v3` ≈ **0.53**；`wd-swinv2-tagger-v3` ≈ **0.27** | 模型卡发布的 P=R 平衡点仅作起点，不可直接当通用最优 |
| **角色阈值** | **保守取 0.85** | 角色标错代价最高，宁漏勿错 |
| **小样标定法** | 抽 10~20 张代表图 → 统计「有效 / 错标 / 漏标」 → **只调一次阈值** → 复抽确认 | 禁止未标定直接全量跑盘 |
| **输出与重排** | 必须经过 `rules/` 规范化与槽位重排 | WD14 原生导出按**置信度降序**排列，会打乱官方段顺序并混入下划线/废弃形 |
| **定位约束** | 产出仅作 **C 源（初稿）** | 仍须经看图子代理核对人数、构图、体位并过 [validate_captions.py](../scripts/validate_captions.py) |
